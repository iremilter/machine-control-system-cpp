# Machine Control System (C++)

This project is a simple simulation of an industrial machine control system developed in C++.

## Features
- Turn machine ON / OFF
- Set speed with maximum speed validation
- Set working timer
- Display machine status
- Automatic shutdown for safety
- Error handling for invalid inputs

## Technologies Used
- C++

## Purpose
This project was created to practice control system logic, state management, and structured programming concepts.

## How to Run
1. Compile the code using a C++ compiler (Visual Studio recommended)
2. Run the program
3. Use the menu to control the machine
